Clinic Excel templates and CSVs

Files included:
- patients.csv
- appointments.csv
- billing.csv
- inventory.csv
- staff.csv

How to use:
1. In Excel, open a new workbook.
2. For each CSV file, go to Data -> Get Data -> From Text/CSV and import the corresponding CSV into a new sheet (or copy/paste the content into sheets named: Patients, Appointments, Billing, Inventory, Staff).
3. After importing, add the formulas and conditional formatting described in the repository issue/README or use the Dashboard sheet template (to be added).
